Schedule I 简体中文静态资源版 v1.4.18
适配：游戏 v0.4.5f2 / Steam Build 22829923

安装
1. 完全退出 Schedule I。
2. 运行 ScheduleIChineseStaticInstaller-v1.4.18.exe。
3. 确认游戏根目录（目录内应有 Schedule I.exe）。
4. 点击“安装 / 更新静态汉化”。
5. 通过 Steam 正常启动游戏。

本版本的工作方式
- 中文直接写入当前版本的 7 个 Unity 资源文件。
- 中文字体通过替换游戏自带 Font 对象的字体数据实现，由游戏自身在运行时渲染。
- 安装时把游戏根目录的 winhttp.dll 移入校验备份，因此 BepInEx 不会进入游戏进程。
- 不需要联网，不在游戏运行时翻译，不修改存档。
- 人名、玩家输入的自定义名称和品种名称按原文保留。

恢复原版
1. 完全退出游戏。
2. 再次运行安装器。
3. 点击“恢复原版”。
4. 安装器会恢复 8 个原版资源，并恢复安装前的 winhttp.dll/BepInEx 状态。

手动卸载
- 优先使用安装器的“恢复原版”按钮。
- 不要只删除备份目录；静态版翻译位于 Schedule I_Data 的资源文件内。
- 如果安装器丢失，可在 Steam 中验证游戏文件恢复资源；BepInEx 的 winhttp.dll 仍需从
  ScheduleIChinese_Static_Backup\Build22829923\Loader 手动移回游戏根目录（如果原先存在）。

已知限制
- 本包只支持 Build 22829923。游戏更新后哈希不同，安装器会拒绝覆盖。
- 运行时生成且从未序列化在资源中的极少量文本无法由纯静态版补译。
- 不同字体的字宽不同，少数固定宽度界面可能出现换行或裁切。
- 安装器不删除 BepInEx 文件夹或其他模组，只停用入口 winhttp.dll；恢复原版时会恢复入口。

手动验收建议
- 加载现有存档并等待进入场景。
- 打开手机联系人和关系网，连续切换多个顾客。
- 查看消息列表、顾客详情、效果词、物品说明、任务和教程。
- 确认人名与自定义名称没有被翻译。
